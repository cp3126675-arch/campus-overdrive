# 主修战斗与实景技能

- 数学系：积分公式刃、正弦波尾迹、穿透与数学符号光环。
- 计算机系：并行代码流、二进制尾迹、近距离追踪纠偏。
- 建筑学院：线框构件弹、基础范围爆破、施工蓝图网格和建筑轮廓结界；保留原近身伤害和减速机制。
- 三类怪物以对应教材封面为本体；DDL 怪加急，Boss 为叠书形态。封面图片来自出版社/教材作者公开页面。
- 学堂路实景来自清华大学电子工程系《你好！新学期》2023-09-19，霍元东摄影；保留移动、推进、冲刺加速。
- 车神技能显示报道中的原照片，0.14 秒淡入、末尾 0.22 秒淡出，最高不透明度 46%；徽章始终后绘制且在冲刺中不闪烁降透明度。
- 鹅腿和鸭腿由画面右侧补给站统一抛出，分走两条曲线，8 秒后飞走；两者起点与补给站共享同一坐标计算。删除原站点被动 +20 HP。
- 结束时立即锁定挑战用时和结局，战斗特效收尾、怪物淡出，2.6 秒后淡入结算；收尾时间不计入挑战成绩。

验证：TypeScript、模型回归；三主修实战模拟均合出最高级，数学 157.1 秒、计算机 118.1 秒、建筑 164.0 秒。核验两类补给同源、站点不回血、结束后成绩冻结和结算进度完成。具体图片来源和权利说明记录于 public/ASSET-CREDITS.txt。
