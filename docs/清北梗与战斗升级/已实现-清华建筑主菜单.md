# 清华建筑主菜单 · 2026-09-07

初始界面改为二校门照片与独立标题菜单。首屏只显示游戏名称、模式、开始游戏、操作说明和音效开关。开始游戏后进入主修选择，仅显示选中主修的战斗描述，点击开始挑战进入现有竞速游戏。键位和完整规则移入操作说明弹窗。

照片：清華匿名學生，2019 年二校門，CC0 1.0；来源 https://commons.wikimedia.org/wiki/File:2019年二校門.jpg 。使用 Wikimedia 提供的 1280px / 3840px 图片，首屏根据设备选择尺寸。仅 CSS 裁切和暗色遮罩；原始像素未改。页面底部和 ASSET-CREDITS.txt 保留来源。

菜单词汇与分步结构参考光荣特库摩官方说明书：
https://www.gamecity.com.tw/manual/shinsei/wpk/sc/3100.html
