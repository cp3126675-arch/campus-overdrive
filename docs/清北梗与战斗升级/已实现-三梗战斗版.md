# 三梗战斗版 · 2026-09-07

本轮只新增学堂路车神、鹅腿阿姨、唯一的隔壁三个主题。

- 空格：0.72 秒可转向骑车撞击，4 秒冷却。每个目标每次骑行只受一次碾压，骑行期间双倍射速。
- 鹅腿：生命 +24（上限 100），5 秒双倍射速；鸭腿：生命 -12，可致死。鸭腿不自动吸附，战斗无敌不抵消食用扣血。这是虚构游戏规则。
- Q：击败敌人 +4、合成 +16、吃鹅腿 +8 充能，100 充能开启 4.5 秒清北双色旋转激光，击杀触发邻近连锁爆炸。技能期间不回充。
- 合成保留原院系/书院徽章与目标链。最高徽章等级推动四档火力：基础、扩散穿透、范围爆炸、终阶弹幕。
- 加入连破计数、冲击射线、车轮残影、命中闪光、轻微停顿及分动作音效。减少动态效果偏好会关闭屏幕震动与闪光。
- 保留作业 DDL、学分、绩点、期末考试、三种主修和手机触控。

## 验证

TypeScript、所改代码 lint、Vinext 生产构建、GitHub Pages 静态构建通过。
真实模型逐帧模拟三种主修均到达结算；数学/建筑约 216 秒胜利，计算机约 231 秒胜利。额外断言检查了鹅鸭腿重复拾取、无敌状态下扣血、车神单次伤害、清北充能与暂停、连锁爆炸、终局状态冻结及徽章火力进化。
没有执行浏览器视觉测试；手机实际流畅度和触控手感仍以玩家体验为准。
