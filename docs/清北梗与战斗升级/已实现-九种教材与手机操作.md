# 九种教材与手机操作

九种教材封面：高等数学、线性代数、概率论与数理统计、数据结构、计算机网络技术基础、操作系统原理与应用、房屋建筑构造、建筑制图与 CAD、这不是中国建筑史。保留每张图原文件，新增六本来源详见 public/ASSET-CREDITS.txt。

同阶段普通怪基础生命分别为 30、48、20、34、24、62、56、26、42，随轮次与合成等级增长。生命、速度、体型各有区别；DDL 精英生命额外乘 1.65，Boss 保留独立生命规则。大多数出自主修，少量跨学科选修怪混入。头顶显示书名与不同长度、颜色、分格的血条。

车神照片从 200×150 增至 232×174，最高不透明度从 46% 改为 88%；淡入 0.08 秒、淡出 0.16 秒。徽章最后绘制且不降透明度。

手机布局：左侧全方向模拟摇杆（小幅推动慢走），右侧三角形技能区；主要合成按钮 72px，其他 64px；横屏收为 62/56px。触摸按下立即响应技能，鼠标及键盘触发保留。摇杆独占其起始 pointerId，第二指技能不会抢走或释放移动；松手、取消、失焦、暂停和尺寸变化重置输入。横竖屏使用安全区域，横屏压缩 HUD，隐藏次要作业栏。保留浏览器缩放能力。

验证：类型和 lint 检查通过；九种书怪生命差异、随机池覆盖、双指所有权、死区/斜向/释放/重置、模拟摇杆速度以及旧玩法回归通过。实际模型三主修均获胜：数学 141.4 秒，计算机 186.0 秒，建筑 174.3 秒。未进行手机真机或浏览器交互测试。
