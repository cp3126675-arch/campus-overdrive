## 原因与实现

使用 `Origin: http://localhost:3000` 对正式 `/api/player` 发起只读 OPTIONS 预检，返回 HTTP 403“来源不允许”；浏览器因缺少允许来源响应而显示 Failed to fetch。生产来源白名单只包含正式游戏地址。

标准开发入口现在用 `wrangler.local.jsonc`、`--local` 和占位数据库 ID 启动本地真实 Worker，复用三次数据库迁移；启动前自动迁移，健康检查成功后启动 Vite。Worker 只监听回环随机端口，Vite 提供开发专用的 `/leaderboard.json` 及 `/api` 同源代理。退出时关闭两个子进程；数据在 Git 忽略目录内持久化。正式配置、数据库和游戏源码不变。
