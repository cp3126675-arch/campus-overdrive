# 缩圈生存与徽章生命：v0.6.3-dev.2

2026-09-08，本地候选，未发布。基于 dev.1 提交 `1d1452ba95305615fd1079e8e6344ee13d92c2b4` 继续开发；原包与源码保持不变。公开游戏仍为 v0.6.2，地图原型仍独立保存。

## 体验目标

死亡来自越来越难的战斗和越来越少的安全空间，玩家可通过走位、合成和破碎后的护盾争取时间。常规玩家目标局长 5–6 分钟；技术好的玩家可更久，没有按固定时间处死的逻辑。此目标仍需真人数据验证。

## 徽章就是生命

中央徽章当前这一级拥有 100 点生命，普通受击不再在 60 / 30 时掉阶。血量耗尽后，处理为一次原子状态变化：

1. 中央徽章只降低一级，超额伤害不穿透到下一级。
2. 全部僚机立即清空，只剩降级后的中央徽章，新徽章恢复 100 生命。
3. 开启 1.2 秒破碎护盾，阻挡普通攻击、圈外伤害、鸭腿扣血。盾形轮廓以 2.5 Hz 平滑明暗闪烁，结束即消失；减少动态效果设置下保持常亮。
4. 1.2 秒按有效游戏时间计算，包括顿帧特效时间，暂停和方向阻断不计时。
5. 如果已经是最低级徽章，则进入原有死亡到结算过渡，不再生成新的一条命。

中央火力与武器等级按当前徽章计算。玩家可以重新拾取和合成；已经飞出的友方子弹按原寿命消失，不继续生成已清空僚机的攻击。新拾取的徽章可以再加入编队。

每次合成恢复 20 生命，合成清华也是 20，不额外叠加竞速的毕业治疗。普通合成、技能、冲刺的原战斗无敌不能抵挡圈外伤害；破碎护盾能完整挡住。

圈尽前保留既有鹅腿、院系技能和任务治疗。圈尽后，只允许合成回血：鹅腿保留火力加餐和技能充能，治疗技能保留攻击部分，Boss 和作业仍给原奖励但不回血。破碎后新徽章的满血是下一条生命，属于徽章分解规则。

## 缩圈时间表

圆心固定在世界坐标 (600, 400)。开始半径 760，覆盖整个 1200×800 战场。移动的实景背景继续保留，安全圈使用世界坐标，手机摄像机与角色不会带着圈一起移动。

|0:00–0:45|1|760，暂不收缩|0|
|0:45–1:30|2|760 → 520|2|
|1:30–2:15|3|520 → 330|4|
|2:15–3:00|4|330 → 190|7|

圈半径连续线性变化，不会跳缩；半径为零时，圆心也算圈外。后续每 45 秒仍进入新压力轮，圈伤维持上限，Boss 强度继续增长。圈伤按实际有效经过时间计算，不依赖显示帧率；破碎护盾期间免除伤害。

圈外淡红覆盖，当前边界亮线，下一阶段边界虚线；圈外玩家旁显示指向安全区的箭头。HUD 显示压力轮、圈外扣血和合成治疗，不占中央战斗区域。圈尽后不再显示一个可躲入的中心点。

## Boss 强化与操作空间

首 Boss 35 秒登场，每次击破后 24 秒下一位；八位阵容持续循环。压力轮由时间推进，不依赖玩家是否快速击破 Boss，避免留一只 Boss 就停住难度。

以 `r = 压力轮 - 1`、`L = 当前中央徽章内部等级（0–14）` 计算：

- Boss 生命倍率：`1 + 0.22r + 0.35 × max(0, r−3)²`。
- 出生 Boss 生命：`round((1800 + 420L) × 生命倍率)`；存活 Boss 跨轮按新旧倍率提高当前与最大血量，保持受伤比例，生命值不按换轮回满。
- 通用敌方伤害倍率：`0.65 × (1 + 0.25r + 0.85 × max(0, r−3)²)`，之后沿用玩家减伤。既影响 Boss，也影响进入通用受伤函数的其他攻击；不放大圈伤和鸭腿伤害。
- Boss 攻击频率倍率：`min(1.65, 1 + 0.09r)`。最快低血阶段范围技能间隔约 2 秒，弹幕间隔约 1.52 秒；保留每个招式原预警时长。
- 弹幕数量倍率：`min(1.8, 1 + 0.12r)`，实际新增数量取整。每种 Boss 保持自身文字、轮胎、蛇形等图案，只在选定弹道旁 ±0.035 弧度加线，保留原有大缺口。
- 出生移速倍率：`min(1.4, 1 + 0.025r)`。

伤害与生命没有玩法封顶。频率、密度、移速有上限，后期以命中代价增长施压，避免招式快到来不及反应。暴击式的大伤害仍只能打碎当前一枚徽章。

## 性能和模式隔离

- 同时敌人 ≤48（含 Boss），敌弹 ≤120、子弹合计 ≤360，范围预警 ≤24。新增预警超出预算时忽略新超量部分，不撤掉已经展示过的预警。
- 地面徽章仍 ≤10；安全圈是有限个 Canvas 路径，护盾是一条轮廓，未新增图片、粒子系统、网络请求或逐像素处理。
- 竞速模式原有治疗值、死亡、合成与 Boss 进度保持不变，新通用治疗方法用于生存圈尽时拦截其他治疗。
- 生存结算不写入本机竞速纪录或全服竞速榜。独立生存排行榜尚未实现。

## 验证与版本保存

`npm test` 包含原竞速和新生存回归。新覆盖缩圈连续性、零半径无安全点、掉阶清空僚机、单击不连降、最低级死亡、1.2 秒护盾的结束 / 暂停 / 顿帧、圈伤与治疗、循环 Boss、跨轮强化、弹量上限和绘图调用约束。

`npm run simulate:survival` 运行 5 个院系 × 3 固定种子；追加 `-- --all` 运行全部 126 个可选院系 / 书院 × 3 固定种子。自动角色会进圈、寻找圈内掉落、避近敌与子弹、主动合成与使用技能，但不预测范围预警。模拟不能替代真人平衡、浏览器视觉或手机 FPS 测试。

本版本与 dev.1 分别封存；公开 v0.6.2 原始 ZIP 与回滚依据保留。此次不推送 GitHub，不修改线上站点或数据库。
