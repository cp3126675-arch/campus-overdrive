# 生存模式：v0.6.3-dev.1 本地候选

2026-09-08。分支 `codex/survival-mode`；基于 v0.6.2 本地文档提交 `0e1b3d2`。没有推送、发布或修改在线排行榜服务。地图原型另存 `codex/prototype-cs-dungeon`。

## 目标与流程

首页选择生存模式 → 选择院系 → 自动攻击、走位、合成 → 循环 Boss → 生命耗尽 → 沿用现有死亡到结算的过渡。结算显示存活时间、击破数、合成次数与掉阶统计。没有胜利条件，也不把生存时间写入竞速榜；独立生存纪录尚未实现。

竞速模式继续采用既有合成进度 Boss 检查点与最终击破通关规则。本候选不包含此前地图原型。

## 首轮数值

|规则|数值 / 行为|
|---|---|
|首个 Boss|有效游戏时间 35 秒|
|下一场|击破当前 Boss 后 24 秒；其中最初 3 秒休整|
|阵容|原有 8 位 Boss 按本局顺序循环，任何时候最多一位 Boss|
|掉阶|生命 ≤60、≤30，各触发一次；单次大伤害越过两档可连掉两阶|
|重新启用|生命恢复到 ≥75、≥45，分别重新启用对应掉阶档|
|徽章变化|中央徽章降一阶，所有超过新中央等级的僚机也降至该等级，最低为第一级|
|修复|继续拾取和合成，输出按当前中央徽章计算；历史最高等级只保留进程含义|
|治疗|鹅腿 +24；鸭腿 −12，沿用直接扣血；Boss 击破 +10；普通合成 +1|
|防止循环治疗|生存取消合出清华时竞速专有的额外 +20；治疗均不能超当前生命上限|
|补给与掉落|沿用鹅腿逐渐减少的补给规则；到达清华后仍允许掉落修复徽章，普通自动掉落最高为第 13 级；Boss 奖励最高为第 14 级（清华前一阶）|
|实体限制|敌人最多 48（含 Boss），子弹总数最多 360；触发总上限裁剪时优先保留至多 180 枚敌弹，余量给友弹；地面徽章最多 10|
|6 分钟后|生命上限每秒减少 0.25，即每分钟 15；治疗、无敌、合成均不能抵消|
|极限|有效游戏时间 12 分 40 秒生命上限归零，强制进入死亡结算；暂停与方向阻断不计时|

阈值是绝对生命值。一直低血不会每帧重复掉阶；已经降到最低阶也不会出现负等级。后期生命上限降低到恢复线以下时，该档无法重新启用，但剩余生命容量仍持续衰减。

以 `m = 有效分钟数`、`b = 已击破 Boss 数`、`L = 当前中央徽章内部等级（0–14）` 计算：

- Boss 生命：`round((1800 + L × 420) × (1 + b × 0.28 + m × 0.12))`，出生时确定。
- 普通敌人生命：现有年级 / 时间 / 进度基础生命再乘 `1 + b × 0.07`，出生时确定。
- 进入通用受伤函数的伤害：`ceil(原伤害 × (1 + b × 0.08 + m × 0.075))`，之后仍接受原减伤规则。鸭腿等直接扣血维持原规则。
- 出生移速倍率：`min(1.55, 1 + b × 0.035 + m × 0.025)`。
- Boss 两类攻击计时器加速倍率：`min(1.8, 1 + b × 0.055 + m × 0.04)`。保持原招式形状和预警，不堆无限弹幕。
- 生命上限：`max(0, 100 - max(0, t - 360) × 0.25)`。

|有效时间|生命上限|
|---|---|
|6:00|100|
|8:00|70|
|10:00|40|
|12:00|10|
|12:40|0|

12:40 是正常运行规则下的终局保障，不是预期每位玩家都应到达的目标。它不包含浏览器被挂起的现实时间，不是服务端反作弊。现有回血或长时间无敌构筑仍可延长生存，但不能阻止生命上限最终归零。

## 验证与后续调参

`npm test` 已包含新生存规则回归；可单独运行 `npm run test:survival`。覆盖单次 / 双档掉阶、回血重启、同阶僚机、重新合成、两轮以上 Boss、无胜利路径、持续满血和无敌仍最终死亡、暂停不计时、实体上限与重新开局。

`npm run simulate:survival` 使用固定种子的自动策略：寻找掉落、避近敌与敌弹、合成、施放技能。其用途是复现死亡和压力曲线，不代表人类水平、手机实机表现或渲染 FPS。

本轮 5 个院系 × 3 个种子，共 15 局，全部死亡。最短 100.1 秒，中位 191.3 秒，最长 274.1 秒。逐局证据见 [模拟结果](../releases/0.6.3-dev.1-balance.json)。

类型 / lint、原竞速回归、新规则回归、静态导出与生产构建通过。未做浏览器画面操作验收、OPPO 微信真机验收或真人平衡测试。图片资源保持 235 张压缩副本、3,174,702 字节；首批 4 张 467,456 字节，未增加图片。

下一轮优先观察：掉阶后的恢复是否有希望、首 Boss 是否太早、治疗系与低机动院系是否有明显差距、手机 HUD 是否遮挡。真人反馈后调整公式，使用新候选版本归档，不覆盖本次原包。
