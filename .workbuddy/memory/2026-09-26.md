## 封路强拆修复（第三轮反馈）
- 用户报告：后期所有学生窝在刷新点不进攻；猜测是寻路发现路被堵就停止进攻——猜测正确。
- 根因：流场为 Infinity（被阻挡块完全封死）时学生原地发呆，只有 46px 内的封锁结构会被攻击；封死区外沿的墙（>46px）没人拆，队伍永久堆积。
- 修复（tower-model.ts）：新增 STUDENT_BREACH_R=240 与 nearestStructure()（优先阻挡块，其次进攻对象/防御塔）；流场 Infinity 的学生主动走向并强拆最近封锁结构，拆墙重置 stuckTimer（不触发自爆）；拆开后 cleanup 重建流场，队伍自然推进。重构了 updateStudents 尾部：here===0 → continue；Infinity → 强拆分支；有限流场 → 看门狗 + 流场移动。
